# Multi-Language Expansion Glossary

Shared school-management terminology for the language expansion work. Keep this as a running ledger: add terms when a translation choice should stay consistent across UI, notifications, PDFs, and future locales.

| English term                    | French                         | Notes                                                     |
| ------------------------------- | ------------------------------ | --------------------------------------------------------- |
| Tutor period                    | Heure de tutorat               | Not "periode"; "heure" fits the school timetable context. |
| Behaviour incident              | Incident de conduite           | Prefer over a literal "incident de comportement".         |
| Scheme of work                  | Programme pedagogique          | UK/Irish school planning term; use the French equivalent. |
| Year group                      | Niveau scolaire                | Use consistently for cohort/year-level grouping.          |
| Form tutor                      | Professeur principal           | Standard French education term.                           |
| Detention                       | Retenue                        | Avoid "detention", which suggests imprisonment.           |
| Merit                           | Bonus de comportement          | Positive behaviour point.                                 |
| Demerit                         | Avertissement                  | Negative behaviour point or sanction marker.              |
| Parent-teacher meeting          | Reunion parents-profs          | Common school phrase.                                     |
| Report card                     | Bulletin scolaire              | Avoid "carte de rapport".                                 |
| Attendance register             | Registre de presence           | School attendance context.                                |
| Safeguarding                    | Protection de l'enfance        | Sensitive area; use official-style terminology.           |
| Special Educational Needs (SEN) | Besoins educatifs particuliers | May be abbreviated as BEP where space is tight.           |
| Headteacher                     | Directeur ou directrice        | Prefer inclusive wording over a gendered default.         |
| Household                       | Foyer                          | Use for the family/account grouping in EduPod.            |
| Fee structure                   | Structure tarifaire            | Finance setup object.                                     |
| Payment plan                    | Plan de paiement               | Parent-facing and finance-facing.                         |
| Credit note                     | Avoir                          | Standard finance term.                                    |
| Pastoral care                   | Accompagnement pastoral        | Student wellbeing/support context.                        |
| Wellbeing                       | Bien-etre                      | Use for module labels and student support content.        |
| Timetable                       | Emploi du temps                | School schedule.                                          |
| Cover                           | Remplacement                   | Staff absence / substitution coverage.                    |
| Admissions                      | Admissions                     | School intake/application area.                           |
| Enrolment                       | Inscription                    | Student enrolment context.                                |
